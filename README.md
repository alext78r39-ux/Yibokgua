# Yibokgua（易卜卦）

以梅花易數為核心的易經起卦 App，提供多種起卦方式與完整 64 卦資料庫，輕鬆在家中完成一次專業的占卜。

## 功能介紹

- **四種起卦方式**，依不同情境自由選擇
- **體用生克分析**：自動判斷體卦、用卦、互卦與變卦，分析吉凶走向
- **64 卦資料庫**：完整收錄卦辭、彖傳、大象傳、六爻爻辭與歷代注解
- **卦象詳情**：清楚顯示本卦、變卦與動爻，點擊卦名即可查閱完整解說
- **深色模式**：支援系統深色主題，夜間使用更舒適

## 安裝方式

1. 下載 APK 安裝檔（`app-debug.apk`）。
2. 於手機上開啟檔案，允許「安裝未知來源的應用程式」。
3. 完成安裝後，開啟「Yibokgua」即可開始使用。

> 系統需求：Android 8.0（API 26）以上。

## 使用方法

App 分為兩個主頁面：「起卦」與「64卦庫」。

### 起卦

於「起卦」頁面選擇以下任一種方式：

| 方式 | 說明 |
| --- | --- |
| 自動搖卦 | 長按太極圖 2 秒生成一爻，依序搖滿六爻成卦 |
| 手動搖卦 | 依「老陰 6・少陽 7・少陰 8・老陽 9」依序指定六爻 |
| 日期 | 輸入起卦的日期與時間，依梅花易數規則推算 |
| 類象 | 輸入物象數與方位數起卦 |

搖滿六爻後，會顯示 **本卦** 與 **變卦**，並附上「體用生克」分析結果。點擊卦名可跳轉至「64卦庫」查看該卦的完整解說。

### 64卦庫

- 瀏覽全部 64 卦，或以卦名、卦序搜尋（例如：乾、坤、1）。
- 點選任一卦象，可查看完整的卦辭、彖傳、大象傳、六爻爻辭與歷代注解。

## 起卦結果怎麼看？

- **本卦**：當前狀況。
- **變卦**：動爻變化後的結果，代表事情的走向。
- **體用生克**：以「體卦」代表自己、「用卦」代表所問之事，透過五行生剋判斷吉凶。
  - 體用比和、用生體、體克用：主吉。
  - 用克體、體生用：主凶或耗損。

## 常見問題

**起卦後想再問一件事？**
按「再算一次」即可重新起卦。

**卦象符號顯示為方塊？**
請確認裝置字型支援易經六十四卦符號（Unicode U+4DC0～U+4DFF），或於系統設定更新字型。
