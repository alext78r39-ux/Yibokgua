## ✨ 功能特色

### 🎯 多元起卦方式

- **自動搖卦**：長按太極圖 2 秒生成一爻，依序集滿六爻成卦。
- **手動搖卦**：自由指定老陰（6）、少陽（7）、少陰（8）、老陽（9），精準自訂卦象。
- **時間起卦**：依傳統梅花易數，結合年、月、日與時分自動推演本卦與動爻。
- **類象與方位起卦**：以物象數與方位數組合起卦，適合隨機占斷。

### 📊 體用生克分析

- 自動辨識體卦、用卦與互卦。
- 推算「體用比和、體生用、用生體、體克用、用克體」五大生克關係。
- 即時呈現吉凶提示，輔助日常決策參考。

### 📚 完整 64 卦資料庫

- 收錄《周易》本經卦辭、彖傳、大象傳。
- 完整六爻爻辭與分爻小象傳。
- 整合王弼、朱熹、孔穎達等歷代名家注解，並附白話淺釋，便於深入研讀。

### 🎨 典雅視覺體驗

- **東方美學配色**：精選朱砂紅、玄金與宣紙米白，營造沉靜質感。
- **深色模式**：完整支援 Dark Mode，夜間使用舒適不刺眼。
- **跨裝置適應**：手機採底部導航（Bottom Navigation），平板採側邊導航（Navigation Rail），自動呈現最佳版面。

## 🛠️ 技術棧與架構

- **開發語言**：[Kotlin](https://kotlinlang.org/)
- **UI 架構**：[Jetpack Compose](https://developer.android.com/jetpack/compose)（Material Design 3）
- **架構模式**：MVVM + 多模組設計（`core` / `engine` / `data` / `app`）
- **非同步處理**：Coroutines & Flow
- **資料來源**：內建 64 卦完整文本資料庫（記憶體 Repository）

## 📖 使用說明

### 1. 選擇起卦方式

- **自動搖卦**：長按太極圖 2 秒，待進度環跑滿即生成一爻。
- **時間起卦**：於「日期」頁選擇起卦的日期與時間（預設帶入當前時間）。
- **手動搖卦**：依序指定六爻，每爻可選擇老陰（6）、少陽（7）、少陰（8）、老陽（9）。
- **類象**：輸入物象數與方位數組合起卦。

### 2. 檢視卦象結果

集滿六爻後，系統自動生成卦象結果，可檢視：

- **卦象推算**：本卦、變卦與動爻位置。
- **生克分析**：體用生克關係、互卦與吉凶評估。
- **經文解析**：點擊卦名即可跳轉「64 卦庫」查看卦辭、彖傳、大象傳、六爻爻辭、分爻小象傳與歷代注解。

## ❓ 常見問題（FAQ）

**卦象符號顯示為方塊？**
請確認裝置字型支援易經六十四卦符號（Unicode U+4DC0～U+4DFF），或於系統設定中更新字型。

**起卦後想再問一件事？**
按下「再算一次」即可重新起卦。

**我的起卦資料會被上傳嗎？**
不會。所有運算皆於本機完成，應用程式不具備任何網路傳輸功能。
